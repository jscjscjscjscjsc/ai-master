// 04 · Work Modes

三种模式：你说我做 · 先想后做 · 只答不做

不同场景需要不同的协作方式。WorkBuddy 提供三种工作模式，自由切换——简单任务直接执行，复杂任务先规划再动手，纯咨询只回答不碰文件。

CRAFT MODE
🔨

执行模式

你说我做。直接读写文件、运行命令、生成内容、交付结果。适合明确的任务——写代码、做报告、处理数据。

你 ▸ 帮我把这个 CSV 转成带图表的 Excel ▸ 读取 data.csv → 清洗数据 ✓ 生成 Excel + 3张图表 ✓ 保存到 output.xlsx
PLAN MODE
📋

规划模式

先想后做。分析需求、设计方案、拆分步骤，等你确认后再执行。适合复杂任务——架构调整、大功能开发、数据库迁移。

你 ▸ 重构用户认证模块 ▸ 分析当前代码结构... ▸ 方案: 改用JWT + Redis 1. 设计Token架构 2. 迁移认证逻辑 3. 添加Redis缓存 ◆ 确认后开始执行？
ASK MODE
💬

问答模式

只答不做。回答问题、读取文件、分析信息，但不修改任何东西。适合咨询——技术选型、代码审查、方案评估。

你 ▸ 这个架构有什么问题？ ▸ 读取架构文档... ▸ 分析发现3个问题: 1. 单点故障风险 2. 缓存策略不合理 3. 缺少熔断机制 ◆ 建议切换到执行模式修复
