# AI Master 星辰学习系统

一套面向「大模型应用与 Agent 全栈开发」的自学平台：**9 章 40 天**课程、
**277 道**练习题、**17 个电影级 CG 与实验室入口**、3D 星海与星际跃迁。
**双击一个 .bat 就能跑，不需要装 Python。**

---

## 一、快速开始

双击 **`0-启动AIMaster.bat`**，浏览器自动打开 <http://127.0.0.1:5178>。

首次启动约 1 分钟（解压随包 Python + 离线装依赖），之后秒开。关闭黑窗口即停止。

- 想保存进度 → 注册账号（数据只存本机 `data/`）。
- 只想看看 → 游客身份可浏览、做题、问智能体，进度不落盘。

换台机器：整个文件夹拷过去，重新双击 .bat 即可。

### 新制的三部 CG

原版有 CG 的只有 Transformer / 提示词 / Agent / Claude Code / RAG 这几个主题，
而新课程里第 2、5、6 章没有对应资产，于是按 `transformer_cg` 的水准新做了三部：

- **`api_engineering_cg.html`** —— 第 2 章，5 幕：一次调用 → 并发（同步串行的阶梯柱
  vs 异步并发的共同起跑线）→ SSE 流式（逐 chunk 到达证据）→ 四道护栏 → 六层后端。
  每一幕对应教材里真实做出来的东西，不是配图。
- **`agent_framework_cg.html`** —— 第 5 章，5 幕：手写概念 → 命名化的状态图
  （State/Node/Edge）→ 条件路由与循环 → Checkpoint 断点续跑 → 人工审批。
- **`multi_agent_cg.html`** —— 第 6 章，5 幕：一个变一群 → 三种协作模式 →
  MCP 无状态协议（三个必需请求头与它们各自防什么）→ 三层成本护栏。
  三种模式刻意用**三种不同的运动方式**表达（接力 / 往返收敛 / 中心分发），
  因为它们的调用结构确实不同 —— 用同一种动画画三种模式等于什么都没说。

为此把原版的 CG 引擎提炼成了 **`static/cg/engine/star-cinema.js`**：
原版每一部 CG 都把那 700 行引擎复制一遍，改一个动效要同步改六处，
最后只有 transformer 那部是新的。提炼之后，新做一部 CG 只需要写 `SCENES` ——
也就是「第几幕讲什么」。引擎还带 `freezeAt(幕, 进度)`，供截图与复核精确停帧。

### 星际导航（跃迁）

`/transition?to=/chapter/5&kicker=SECTOR 05` —— 学完一章去下一章时走这个过场：
大师打坐剪影 + 打字机引言 + **放射状星轨**（速度线从中心向外加速）。
原版只留下 js+css、宿主页面丢失、目的地与时长都写死，现已恢复为可配置页面
（`hold=1` 可停住不跳，用于截图）。

### 3D 知识星海

`/stars` 直接发原版那套 three.js 星海：拖拽旋转、滚轮缩放、射线拾取、
星系/星球两级导航、聆听星语、画质三档。数据来自 `/api/knowledge-universe`，
所以它反映学生的**真实进度**，而不是导出时的静态快照。

## 四、五个核心系统

### 星语 · 全局智能体（平台主线）

它和其他答疑助手的区别是**能产生副作用** —— 不只回答，还把你送到该去的页面。

| 你说 | 它做什么 |
| --- | --- |
| 我对 MCP 不熟悉 | 跳到第 6 章对应那一节并讲重点 |
| 我想做 RAG 的题 | 打开第 3 章练习列表 |
| 我该怎么安排学习？ | 打开逐日学习路线 |
| 我现在什么水平？ | 打开星空修为，报出还差多少 |
| 我想模拟面试 | 打开星辰教练面试模式 |

三层实现：**本地意图识别**（问路类不烧 token，零延迟）→ **课程检索**（讲的和
章节里写的是同一套说法）→ **动作白名单校验**（章节存在、知识点编号合法、
地址由服务端拼装，所以不可能给出打不开的页面）。任意页面 Ctrl+K 唤起。

### 逐日学习路线

选每天能投入多久（30 分钟 / 1 小时 / 1.5 小时 / 3 小时），路线自动重排。
每个知识点的学时按正文长度估算，装不下顺延到明天；每个阶段结束有复盘日，
全部学完有冲刺日。已完成的知识点会被划掉，所以它是活的。

### 分章练习与 AI 批改

277 道题覆盖全部 40 天：选择题本地即刻判；简答与代码题由 AI 对照
「标准答案要点」逐条核对后评分，返回四项：**分数 / 总评 / 答到的地方 / 还差的**，
总评会引用你答案里的原话说明依据 —— 这样分数才可复核。
另有 **AI 组卷**：随机抽题限时完成，交卷后逐题讲评 + 未来三天复习建议。

> 卡住时点「不会，给点思路」—— 只给方向不给答案，**且不扣分**。
> 这一点是刻意的：如果求助有代价，学生会宁愿空着也不问。

### 星辰教练 · 模拟大模型面试

- **答疑模式**：陪练式讲解，末尾必跟一句「想一想」推动你自己讲清楚。
- **面试模式**：按你的薄弱章节开场，一次只问一个问题，答完当场评分点评
  （指出具体缺口），答得含糊就追问、答得好就加深难度；走满六轮自动收尾给整场总结。
- **语音问答**：可开关朗读（服务端 edge-tts，失败自动退回浏览器语音），
  也可以按住麦克风用说的提问。

### 星空修为

十一阶境界线：观星者 → 拾光者 → 航星者 → 绘轨者 → 折光者 → 构星者 →
织星者 → 驭星者 → 摘星者 → 燃星者 → 星系织者（33 级）。配：

- **星仪** 33 件 —— 每级一件真实天文器材（星图笔记 → 六分仪 → 干涉仪 →
  星系动力学模型…），每件对应一种具体能力，不是凑数的装饰。
- **星器** 12 件 —— 解锁条件全是累计统计（首次通关、满分次数、连续天数、错题订正…）。
- **星辰试炼** 11 场 —— 每个大境界三条目标，全达成发一次突破奖励。
- **探索战力** —— 六项加权求和，每一项都能在下钻面板里对上真实数据。

## 五、性能与响应

- **本地意图识别**：问路类问题不调模型（实测 0 延迟）。
- **三层缓存**：课程检索 15 分钟 / 回答 600 秒（上限 500 条）/ 语音按内容哈希。
- **关闭思考过程**：推理模型的思考会把首字延迟从 2 秒推到 8 秒；学习场景默认关掉。
- **建连重试**：服务商偶发不响应（实测一次卡 47 秒）时重试 3 次，
  但**流一旦开始吐字就不再重试** —— 避免把已经显示给学生的半截回答重来一遍。

实测：普通提问首字 1.8 秒、完整回答 3–4 秒；缓存命中 5 毫秒内；AI 评分 3 秒内。

## 六、技术结构

```
AI Master 学习平台/
├── 0-启动AIMaster.bat      一键启动（唯一需要双击的文件）
├── app.py                  Flask 主应用：路由 / RAG / SSE / 用户
├── ark_client.py           大模型传输层（额度降级、重试、流式）
├── starlab_engine.py       题库、判分、积分账本、逐用户存储
├── star_engine.py          境界、法相、星仪、星器、试炼（纯推导）
├── roadmap.py              逐日路线排布
├── coach_engine.py         会话存储与提示词库（不调模型）
├── tts_engine.py           语音合成（edge-tts + 浏览器兜底）
├── demo_mode.py            评审演示账号（改动只在内存，不落盘）
├── data/                   课程表、题库、CG 注册表、用户存档
├── static/
│   ├── cg/                 电影级 CG（含 engine/ 与三部新制）
│   ├── lab/                实验室（Transformer / BPE / 训练模拟器）
│   ├── atlas/              3D 星海 + 星际跃迁（three.js r128）
│   ├── course-assets/      教材真实运行截图与图表（46 张）
│   └── css|js/             平台前端
├── templates/              12 个页面
├── tools/                  内容生成与自检工具
├── runtime/ vendor/        随包 Python + 离线依赖（免安装）
└── logs/shots/ cg-shots/   验收截图
```

设计上刻意的取舍：

- **只依赖 flask 与 edge-tts**。HTTP、JSON、子进程、线程、哈希全部用标准库，
  依赖越少，"解压即用"越不容易在学生机器上失败。
- **判分逻辑只有一份**（`static/js/qcards.js`）。章节页与刷题页共用同一份实现 ——
  复制两份意味着同一个答案可能在一处算对、另一处算错。
- **修为只推导、不存状态**。装备与试炼的达成条件全是累计统计，口径不变则同一份
  作答数据在任何地方都推出同一结果，不会出现存档与事实不一致的脏数据。
  唯一落盘的只有试炼奖励。
- **章节 ↔ 视觉资产只有一份定义**（`tools/attach_cg_assets.py` 的注册表）。
  加一个 CG 只改一处，章节页 / 智能体 / 星海都从这里取。

## 七、自检工具（`tools/`）

内容与页面都能自查，不需要人肉点：

```bash
# 内容
python tools/build_course_from_textbook.py   # 教材 → 课程数据（含图片路径改写）
python tools/build_question_bank.py          # 逐知识点生成题目（可中断续跑）
python tools/content_check.py                # 校验 9 章正文/小节/题目/展开状态
python tools/verify_assets.py                # 校验所有资源引用是否真的存在

# 视觉资产
python tools/attach_cg_assets.py             # 装配 CG 注册表 + 修正搬过来的路径
node tools/cgcheck.mjs                       # CG 运行时自检（14 个页面）
node tools/shoot_cg.mjs                      # CG 精确停帧截图
node tools/shoot.mjs                         # 平台整页截图（带登录态）

# 页面与链接
python tools/check_links.py                  # 遍历 39 个页面的全部内链，查 404
python tools/shoot_pages.py                  # 逐页离屏截图
node tools/inspect.mjs /training             # 容器几何 + 命中测试
node tools/jscheck.mjs /coach                # 运行时 JS 错误
```

**为什么需要 `check_links.py`**：原版的 CG 是用相对路径互相引用的
（`ai_odyssey.html` 里的卡片写 `transformer_cg.html`，假设同目录就有 CG），
直接搬进平台的目录结构后，第一层页面能打开、第二层全是 404 ——
而这类问题在截图里完全看不出来（页面本身渲染正常）。
这个脚本把每个 `href`/`src`/`data-target` 按「页面所在目录」解析后逐个请求，
一次查出全部断链。当前结果是 **39 个页面、614 条内链、0 个 404**。

另外两个关键实现细节：

- `cgcheck.mjs` / `shoot_cg.mjs` 用 **SwiftShader 软件渲染**。无头环境没有 GPU 时
  WebGL 上下文创建会静默失败，three.js 页面停在 canvas 默认尺寸 300×150 ——
  看起来像页面坏了，其实是没 GPU。
- `shoot_cg.mjs` 用引擎的 `freezeAt(幕, 进度)` **精确停帧**，而不是「跳过去然后 sleep」。
  后者只能靠猜等待时间，截到的常是刚开场的中间态（看着像 CG 没画出来），而且不可复现。

## 八、配置

模型配置在项目根目录 `.env`：

```ini
STARLAB_AI_BASE_URL=https://opencode.ai/zen/go/v1
STARLAB_AI_MODEL=deepseek-v4.1-flash
ARK_API_KEY=sk-...
STARLAB_AI_FALLBACK_MODELS=
STARLAB_AI_THINKING=disabled
```

也可在网页里改（`POST /api/setup` 会写回 `.env` 并热重建客户端，不必重启服务）。
`GET /api/ai-status` 返回通道连通性自检。

评审演示账号（可选）：设 `STARLAB_DEMO_USER=reviewer` 与
`STARLAB_DEMO_PASSWORD=xxx` 后启动。它有一份预置的学习档案（能直接看到真实的
修为、星器与进度，不是空壳），但所有改动只在内存里，重启即还原。
